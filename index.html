O que é Sensoriamento?

Sensoriamento é o processo de captar grandezas físicas ou químicas do ambiente (temperatura, luz, pressão, presença de gás, etc.) e converter em sinais elétricos que podem ser lidos e processados por dispositivos eletrônicos.

Importância na Automação Industrial

Sem sensores não existe automação. Eles são os "olhos e ouvidos" das máquinas, permitindo que sistemas tomem decisões em tempo real: parar uma esteira ao detectar peça fora do lugar, ajustar temperatura de um forno, alertar sobre vazamento de gás, entre outras aplicações.

Sensores + Comunicação + Controle

O sensor coleta o dado, a rede de comunicação (I2C, SPI, MQTT, Modbus, LoRa) transporta a informação e o controlador (Arduino, ESP32, CLP, nuvem) toma a decisão. Esse ciclo é o coração da Internet das Coisas (IoT) e da Indústria 4.0.

Arduino – Conceito, funcionamento e programação

O que é o Arduino?

O Arduino é uma plataforma de prototipagem eletrônica open-source composta por uma placa microcontrolada (baseada em ATmega328 no UNO) e um ambiente de desenvolvimento (IDE) baseado em C/C++. Permite ler entradas – luz em um sensor, um dedo em um botão, uma mensagem de rede – e transformar em saídas – acionar um motor, ligar um LED, publicar dados online.

Características principais

  • Microcontrolador ATmega328P (Arduino UNO)
  • Alimentação 7–12 V (jack) ou 5 V (USB)
  • 14 pinos digitais (6 com PWM) e 6 analógicos (10 bits)
  • Comunicação: UART, I2C (A4/A5) e SPI (D10–D13)
  • IDE multiplataforma com centenas de bibliotecas prontas

Funcionamento básico de um programa (sketch)

void setup() {
  // Executado uma vez ao ligar/resetar
  pinMode(13, OUTPUT);
}
void loop() {
  // Executado repetidamente
  digitalWrite(13, HIGH); delay(500);
  digitalWrite(13, LOW);  delay(500);
}

Temperatura e Umidade

DHT11

Monitoramento de temperatura e umidade

Conceito
Sensor digital de baixo custo que mede temperatura e umidade relativa do ar em um único módulo.
Princípio de funcionamento
Utiliza um termistor NTC para temperatura e um sensor capacitivo de polímero para umidade. Um microcontrolador interno converte os valores e envia via protocolo digital de fio único.
Especificações técnicas
Alimentação 3.3–5V; Temp: 0–50°C (±2°C); Umidade: 20–90% (±5%); Taxa: 1 Hz.
Tipo de sinal
Digital (1-Wire proprietário)
Aplicações industriais / IoT
Estações meteorológicas, estufas, controle de HVAC residencial, monitoramento de datacenters simples.
Exemplo de uso em projeto
Ligado a um Arduino UNO no pino D2 com biblioteca DHT.h para exibir temperatura e umidade em um display LCD I2C.
Fabricantes / modelos comerciais
Aosong, ELEGOO, Robocore, HiLetgo

DHT11 – Temperatura e Umidade 
#include <DHT.h>
#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}
void loop() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  Serial.print("Temp: "); Serial.print(t);
  Serial.print(" C | Umid: "); Serial.println(h);
  delay(2000);
}
LM35 – Temperatura analógica 
void setup() { Serial.begin(9600); }
void loop() {
  int leitura = analogRead(A0);
  float tempC = (leitura * 5.0 / 1023.0) * 100.0;
  Serial.print("Temperatura: ");
  Serial.print(tempC); Serial.println(" C");
  delay(1000);
}
HC-SR04 – Distância ultrassônica 
#define TRIG 9
#define ECHO 10
void setup() {
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  Serial.begin(9600);
}
void loop() {
  digitalWrite(TRIG, LOW); delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long dur = pulseIn(ECHO, HIGH);
  float cm = dur * 0.0343 / 2;
  Serial.print("Dist: "); Serial.println(cm);
  delay(300);
}

MFRC522 – Leitor RFID 
#include <SPI.h>
#include <MFRC522.h>

  Serial.begin(9600); SPI.begin(); rfid.PCD_Init();
}
void loop() {
  if (rfid.PICC_IsNewCardPresent() && rfid.PICC_ReadCardSerial()) {
    Serial.print("UID: ");
    for (byte i=0;i<rfid.uid.size;i++) {
      Serial.print(rfid.uid.uidByte[i], HEX); Serial.print(" ");
